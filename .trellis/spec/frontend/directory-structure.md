# Directory Structure

> How frontend code is organized in this project.

---

## N/A — No Frontend

This is an STM32F407 embedded C firmware project. There is no web frontend, no UI framework, no client-side code.

All user-facing interaction is via hardware peripherals (GPIO/LED, buttons, UART, etc.) managed by the firmware in `Core/`.

If a companion UI (PC tool, mobile app, web dashboard) is added in the future, document its structure here.
